# Old rules

Rulebooks the game no longer uses, kept for reference. The rulebook today is the website's (`site/rulebook/`, one text
file per chapter); Card sync prints it to `TTS/Rulebook/Rulebook.pdf` for the Tabletop Simulator save.

- `Rulebook/`: the Photoshop rulebook (48 pages, `00_Table_of_Contents` to `22_Negation`, and the covers), used until
  2026-10-29. Its text and pictures became the website's chapters.
- `Very Old Rulebook/`: the first rules pages (`01_Start_of_the_Game` to `21_DEF_Sheet`), from before that.
