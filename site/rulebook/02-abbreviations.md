# Abbreviations

> [!kirby] “***X***” is a variable that can represent any number!

## GENERAL
SP = Star Points. DMG = Damage. HP = Health stat.
ATK = Attack stat. DEF = Defense stat. SPD = Speed stat.

::: row
## TIME FRAME
(OYT) = On your turn.
(AAT) = At any time.

## GENERAL
PF = Primary field.
CDMG = Counter damage.
:::

## 🕐ON YOUR TURN
> [!kirby right] These imply (OYT).

(XPT) = ***X*** time(s) per turn.
(EXT) = Every ***X*** turns (starting on the ***X***th turn).⏳
(FTEXT) = Every ***X*** turns (starting on the 1st turn).⏳

## 🕐AT ANY TIME
> [!kirby right] These imply (AAT).

(XPGT) = ***X*** time(s) per global turn.
(EXGT) = Every **X** global turns.⏳

## 🕐FORCED
> [!kirby right] All of these must happen automatically.

(BOT) = Beginning of turn.
(ENDT) = End of turn.
(BOGT) = Beginning of global turn.
(ENDGT) = End of global turn.

::: row
## FORCED
(OFS) = On first summon.
(OS) = On summon.
(OD) = On death.
(WOF) = While on field.

::: stack
## PER GAME
(XPG) = Ability can only be activated ***X*** time(s) per game.

---

::: small {.center}
Abilities marked with ⏳ are considered "multi turn" abilities.
Abilites marked with 🕐 are considered "time based".
Time based abilities are considered "refreshed" and become usable again in the specified timeframe.
:::
:::
:::

> **Purple:** at any time ((1GCD), (AAT)).
> **Red:** forced ((BOT), (ENDT), (BOGT), (ENDGT)).
> **Orange:** per game and triggers ((1PG), (2U), (OFS), (OS), (OD), (WOF)).
> **Grey:** costs the creature's action ((Action)).
