# Impossibility Simulator

A Tabletop-Simulator port of a card game created by https://github.com/JasonBechdolt and maintained by friends since middle school.

**[Card browser](https://michaeljsr.github.io/TTSCardMaker/)**: every card, the rulebook, a deck builder, stats and balance analytics. Team members can fix card data there.

**Tabletop Simulator save**: [`TTS/Impossibility Simulator.json`](https://raw.githubusercontent.com/MichaelJSr/TTSCardMaker/main/TTS/Impossibility%20Simulator.json) (put it in `Documents/My Games/Tabletop Simulator/Saves/`). A GitHub Action keeps it current: new cards join their decks (`TTS/decks.json`), image links point at each card's latest commit, names follow the card browser.
